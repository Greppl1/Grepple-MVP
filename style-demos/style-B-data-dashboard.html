How It Works

三步上线你的 MCP 工具

From submission to production-ready, powered by agent-driven diagnostics.

01
Submit 提交工具

提交你的 MCP tool manifest。我们解析 schema、描述和参数定义，生成初始指纹。

02
Diagnose Agent 诊断

多个 agent 尝试发现并调用你的工具，自动评估 discoverability、callability 和 schema 健康度。

03
Launch 上线排行

获得评分和改进建议。优化后重新提交，进入公开排行榜，被更多 agent 选中和调用。
