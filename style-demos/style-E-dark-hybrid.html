Workflow
工作流程
三步让你的工具上线并被全球 agent 调用。
1

提交工具

Submit

上传你的 MCP 工具 manifest，包括工具名称、描述、参数 schema 和调用示例。

2

自动诊断

Diagnose

Grepple agent 自动测试工具可发现性、可调用性，给出评分和改进建议。

3

发布上线

Launch

工具通过诊断后自动进入公开注册表，开始被全球 agent 发现和调用。
